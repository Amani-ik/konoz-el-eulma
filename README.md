# 📍 كنز العلمة - Konoz El Eulma

أول دليل رقمي وتفاعلي مخصص للمناطق التجارية بمدينة العلمة (شارع دبي، شارع المواعين، إلخ)[cite: 5].

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Backend / Database:** Firebase (Hosting, Cloud Firestore)[cite: 4].
- **Frontend:** HTML5, CSS3 (Custom Design), JavaScript (ES6+)[cite: 5].
- **Weather API:** OpenWeather integration[cite: 5].
- **IMGBB API:** To receive images from the user[cite: 5].

## 🚀 كيفية التشغيل (Setup)

1. قم بتحميل المشروع (Clone)[cite: 5].
2. قم بتثبيت أدوات Firebase CLI محلياً لإدارة السيرفر والقواعد[cite: 4].
3. افتح ملف `index.html` في أي متصفح حديث أو ارفعه حياً عبر الأمر `firebase deploy`[cite: 4, 5].

## ✍️ تعديل المحتوى وإدارة البيانات (Admin Guide)

تم تنظيم هيكلة البيانات برمجياً لرفع أداء المنصة وتقليل استهلاك السيرفر[cite: 4]:

### 1️⃣ البيانات الحية والديناميكية (Firestore):

- **الأخبار / الإعلانات / التقييمات:** يتم جلبها حياً من قاعدة البيانات[cite: 4, 5].
- **قواعد الأمان (`firestore.rules`):** تم ضبط قواعد الوصول بحيث يُسمح للعامة بالقراءة فقط من مجموعات البيانات العامة (مثل `services`) وحصر الكتابة والتعديل للمشرفين فقط[cite: 4].

### 2️⃣ البيانات الثابتة والمحلية (`data.js`):

- **المحلات وقائمة مرافق "من حولي" (Around Me):** تشمل المطاعم، المقاهي، المراقيد والصيدليات[cite: 4].
- **روابط الملاحة:** تُحفظ كروابط مباشرة (Direct Links) لتنبثق فوراً داخل تطبيق Google Maps الرسمي لتفعيل توجيه الـ GPS الشخصي للمستخدم[cite: 4].

## 🌐 تحسين محركات البحث وتهيئة الـ PWA

- تم ضبط ملف الـ `manifest.json` وكود الـ HTML الأساسي ليتوافق مع معايير عناكب قوقل (Crawlers)، مما يضمن ظهور اسم التطبيق **"Konoz El Eulma"** والأيقونة الخضراء الرسمية والوصف المحدث بشكل صحيح في نتائج البحث الحية.
